# CodeAlpha Education App UI/UX

A UI/UX design project completed as part of the CodeAlpha Internship.

## Project Overview

This project focuses on designing a modern and user-friendly Education App called **LearnHub** using Figma.

The project includes low-fidelity wireframes, high-fidelity UI designs, and a clickable prototype.

## Tasks Completed

### Task 1 – Low-Fidelity Wireframing
Created the basic structure and layout of the LearnHub Education App using wireframes.

### Task 2 – High-Fidelity UI Design
Converted the wireframes into a polished UI design using colors, typography, buttons, icons, and visual elements.

### Task 4 – Mini Project – Clickable Prototype
Created a clickable prototype of the LearnHub Education App to demonstrate the complete user flow and navigation.
